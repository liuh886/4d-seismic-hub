# 4D Seismic Fact Check Guide

## Verification Heuristics

### 1. NRMS (Repeatability)
- **Excellent (<10%)**: Usually reserved for Fiber-optic PRM or deepwater OBN with perfect source repetition.
- **Good (10-20%)**: Modern high-density OBN or steerable streamer in low-noise environments.
- **Moderate (20-40%)**: Legacy streamer or high-density land geophone.
- **Note**: Always check if the value is a "Median" across the whole survey or just a "Best-case" window.

### 2. Bin Size
- **Deepwater Streamer**: Typically 12.5m x 12.5m or 12.5m x 18.75m.
- **High-Density OBN**: Often 6.25m x 6.25m or 12.5m x 12.5m.
- **Land**: 10m x 10m or 20m x 20m.
- **Verification**: If a paper reports "25m", check if it refers to the receiver group spacing or the subsurface bin.

### 3. Drivers (Main Physics)
- **Saturation**: Primary signal in high-porosity turbidites (e.g., West Africa).
- **Pressure**: Primary signal in stiff carbonates (e.g., Middle East) or undersaturated oil.
- **Compaction**: Identified by time-shifts in the overburden (e.g., North Sea Chalk).
